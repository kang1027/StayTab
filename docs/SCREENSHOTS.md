# StayTab 배포 이미지 가이드

README와 릴리스에 사용하는 이미지는 실제 StayTab 빌드에서 캡처합니다. 사용자 데이터,
로컬 프로젝트명, 한국 전용 앱이 보이는 이미지는 공개하지 않습니다.

## 메인 스위처 이미지

- macOS와 StayTab을 다크 모드로 설정합니다.
- 패널 크기는 70%, 레이아웃은 Grid View, 창 제목 표시는 끔으로 설정합니다.
- Always에는 ChatGPT, Docker, Mail, Music, Obsidian, Warp, Zen을 둡니다.
- Docker는 종료해 `Launch` 상태가 보이게 합니다.
- Running now에는 System Settings, Notion Calendar, Figma, Slack만 둡니다.
- StayTab 설정창과 다른 임시 앱은 닫습니다.
- `⌘Tab`을 길게 눌러 패널을 표시한 뒤 원본 Retina 해상도로 캡처합니다.
- 패널 바깥의 개인 화면은 제거하고, 앱 이름과 점프 키가 선명한지 확인합니다.

현재 README 자산은 `assets/switcher-hero.png`이며 1376×744 PNG입니다.

## 설정 이미지

- Apps 화면의 Always 목록 전체와 점프 키 입력란이 보이게 합니다.
- 공개 스위처 이미지와 같은 앱 순서를 사용합니다.
- 검색어, 사용자 경로, 계정 정보가 없는지 확인합니다.

현재 README 자산은 `assets/settings-pinned-apps.png`이며 878×650 PNG입니다.

화면에 포함된 제3자 앱 아이콘과 상표의 권리는 각 소유자에게 있습니다.
