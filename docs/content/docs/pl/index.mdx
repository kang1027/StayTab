## 1. Instalacja

<Tabs items={['Homebrew', 'Pobieranie']}>
<Tab value="Homebrew">

```bash
brew install --cask bettercmdtab
```

W przypadku wersji przedpremierowych:

```bash
brew install --cask bettercmdtab@beta
```

</Tab>
<Tab value="Pobieranie">

Pobierz najnowszy podpisany plik `.dmg` ze
[strony wydań](https://github.com/rokartur/BetterCmdTab/releases), otwórz go, przeciągnij
`BetterCmdTab.app` do `/Applications` i uruchom aplikację.

Aplikacja jest podpisana i notaryzowana, więc Gatekeeper otworzy ją bez ostrzeżenia.

</Tab>
</Tabs>

BetterCmdTab działa na pasku menu — nie ma ikony w Docku ani głównego okna. Po
uruchomieniu znajdź jego ikonę na pasku menu.

## 2. Przyznanie uprawnienia Dostępność

To uprawnienie jest obowiązkowe. BetterCmdTab potrzebuje Dostępności, aby zainstalować
globalne przechwytywanie zdarzeń ⌘Tab i odczytywać listy okien.

1. Otwórz **Ustawienia systemowe → Prywatność i ochrona → Dostępność**.
2. Włącz **BetterCmdTab**.

<Callout type="warn" title="⌘Tab nic nie robi?">
Prawie zawsze oznacza to brak uprawnienia Dostępność. Przełącznik nie uruchamia się,
dopóki uprawnienie nie zostanie przyznane — aplikacja sprawdza je okresowo, więc
wystarczy przyznać je podczas jej działania, choć zamknięcie i ponowne uruchomienie
również zadziała.
</Callout>

### Karty przeglądarki wymagają drugiego uprawnienia

Dostępność wystarcza do wszystkiego poza kartami **przeglądarki**. Pobieranie listy kart
z Safari, Chrome, Arc, Brave, Edge i podobnych aplikacji korzysta z Apple Events, które
macOS kontroluje osobno w sekcji **Prywatność i ochrona → Automatyzacja**.

Otwórz **Ustawienia → Zachowanie → Karty → Dostęp do kart przeglądarki** i naciśnij
**Sprawdź dostęp…**, pozostawiając otwarte okno ustawień — macOS wyświetla prośbę o zgodę
tylko wtedy, gdy okno jest aktywne, i pyta raz dla każdej przeglądarki. Jeśli pominiesz
ten krok, `\` w wierszu przeglądarki, `expandBrowserTabsAsWindows` oraz
`searchExpandsBrowserTabs` będą po cichu zwracać puste wyniki.

Karty natywne (Finder, Terminal, TextEdit) korzystają z Dostępności i nie wymagają
niczego więcej.

## 3. Przełączanie

| Czynność | Klawisze |
| --- | --- |
| Otwórz przełącznik | Przytrzymaj `⌘` i naciśnij `Tab` |
| Przejdź do przodu / do tyłu | `Tab` / `⇧Tab` lub klawisze strzałek |
| Zatwierdź i przełącz | Puść `⌘` |
| Przełącz bez pokazywania panelu | Szybko naciśnij `⌘Tab` |
| Przełączaj okna aktywnej aplikacji | `` ⌘` `` |
| Szukaj | `/`, a następnie zacznij pisać |
| Przejdź do pozycji | Wpisz widoczną na niej literę |
| Podejrzyj karty okna | `\` |
| Podejrzyj okna aplikacji | `↓` (patrz niżej) |
| Anuluj | `Esc` |

Poniższe czynności dotyczą wyróżnionej pozycji. Wszystkie można przypisać osobno dla
każdego profilu w **Ustawienia → Profile**; ustawienia domyślne to:

| Czynność | Klawisze |
| --- | --- |
| Zamknij okno | `⌘W` |
| Minimalizuj okno | `⌘M` |
| Ukryj aplikację | `⌘H` |
| Zamknij aplikację | `⌘Q` |
| Wymuś zamknięcie aplikacji | `⌘⌥Q` |
| Pełny ekran | `⌘F` |

`↓` przechodzi do okien aplikacji tylko tam, gdzie w innym przypadku nie wykonywałby
użytecznej czynności — w układzie siatki i podglądu okien, gdy panel ma jeden wiersz.
W układzie listy i wielowierszowej siatce `↓` nadal przesuwa zaznaczenie. Funkcja wymaga
też włączenia [`windowDrillEnabled`](/config-reference#windowDrillEnabled), jednego
wiersza na aplikację ([`applicationsOnly`](/config-reference#applicationsOnly)) oraz
aplikacji z co najmniej dwoma oknami.

Szybkie naciśnięcie przełącza natychmiast, bez wyświetlania czegokolwiek. Panel pojawia
się dopiero po przytrzymaniu skrótu przez czas określony w
[`revealDelayMs`](/config-reference#revealDelayMs) (domyślnie 100 ms) — zwiększ tę
wartość, jeśli panel miga podczas szybkiego przełączania.

## 4. Dostosowanie

Otwórz **Ustawienia** z ikony na pasku menu. Dostępne panele to Ogólne, Profile, Okna,
Zachowanie, Aplikacje, Wygląd, Prywatność, Eksperymentalne i Informacje.

Trzy zmiany, które warto wprowadzić od razu:

- **Układ** — Wygląd → Układ. Wypróbuj `Podglądy okien`, jeśli pracujesz z wieloma
  oknami tej samej aplikacji.
- **Pokaż okna z** — Zachowanie → Zawartość. Przy wielu monitorach opcja
  `Widoczne biurka` pokazuje to, co faktycznie znajduje się na ekranie, i ukrywa okna
  pozostawione na biurkach w tle.
- **Pozostaw otwarte** — Zachowanie → Klawiatura. Panel pozostaje widoczny po puszczeniu
  `⌘`, dzięki czemu możesz spokojnie przeglądać pozycje i zatwierdzić wybór klawiszem
  `Return`.

## 5. Opcjonalnie: przenieś ustawienia do pliku

Jeśli przechowujesz pliki konfiguracyjne w repozytorium albo chcesz porównywać i
wersjonować swoją konfigurację, włącz plik konfiguracyjny:

**Ustawienia → Ogólne → Kopia zapasowa → Plik konfiguracyjny → Utwórz…**

Spowoduje to zapisanie bieżących ustawień w `~/.config/bettercmdtab/config.json` i
uruchomienie dwukierunkowej synchronizacji na żywo — zmiany w pliku są stosowane
natychmiast, a zmiany w oknie ustawień zapisywane z powrotem.

```json title="~/.config/bettercmdtab/config.json"
{
  "$schema": "schema.json",
  "layoutMode": "windowPreview",
  "spaceScope": "visibleSpaces",
  "stayOpenOnRelease": true,
  "revealDelayMs": 150
}
```

Zobacz [Plik konfiguracyjny](/configuration), aby poznać działanie synchronizacji,
oraz [dokumentację konfiguracji](/config-reference), aby przejrzeć wszystkie klucze.
