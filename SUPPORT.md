# Support

## Questions and setup help

Use [GitHub Discussions](https://github.com/kang1027/StayTab/discussions) for installation help, configuration questions, and workflows that are not clearly bugs.

Before posting, check the [README](README.md) and search existing discussions and issues.

## Bug reports

Open a [bug report](https://github.com/kang1027/StayTab/issues/new?template=bug_report.yml) when StayTab behaves incorrectly. Include:

- the StayTab and macOS versions;
- the exact key sequence and expected result;
- the apps, window state, Space, and display involved;
- a short recording for focus, layout, or rendering problems when possible.

Please remove private window titles, account names, notifications, and other personal information from screenshots and recordings.

## Feature requests

Open a [feature request](https://github.com/kang1027/StayTab/issues/new?template=feature_request.yml) and describe the workflow or problem first. A concrete user need is more useful than prescribing a specific implementation.

## Security

Do not post vulnerabilities or permission-boundary problems in a public issue. Follow [SECURITY.md](SECURITY.md) and use a private GitHub security advisory.
