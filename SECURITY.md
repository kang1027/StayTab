# Security Policy

## Supported versions

Only the latest public StayTab release receives security fixes.

## Private reporting

Do not open a public issue for vulnerabilities involving Accessibility permission, global event taps, application-switching state, browser automation, update verification, signing, or another permission boundary.

Use **Security → Report a vulnerability** in the [StayTab repository](https://github.com/kang1027/StayTab/security/advisories/new) to create a private security advisory.

Include:

- the StayTab and macOS versions;
- exact reproduction conditions and expected impact;
- a minimal proof of concept when possible;
- whether the issue requires Accessibility, Automation, or Full Disk Access.

Do not attach passwords, tokens, certificates, signing keys, real account data, or unrelated private files.

## Response

The maintainer will acknowledge a valid private report, investigate affected versions, and coordinate a fix and disclosure timeline based on severity and exploitability. Please allow a reasonable remediation period before public disclosure.
